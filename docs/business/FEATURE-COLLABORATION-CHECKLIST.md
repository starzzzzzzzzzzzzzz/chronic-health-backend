# 业务—功能—子功能与前后端协作清单

日期：2026-10-18。依据当前 Controller、业务说明及接口索引整理，覆盖当前 **41 个不同接口操作**。行数不等于接口数：一个接口可支撑多个子功能，一审和二审共用部分审核接口。

用于双方逐项确认业务范围、选择调用入口并记录联调结果。云端地址及凭证使用方式见 [前端云端联调交接](../FRONTEND-CLOUD-HANDOFF.md)。

## 口径

- 增删改查按业务对象变化分类，不按 HTTP 方法直接判断。审核、生成、发布还包含校验、计算和状态流转。
- “角色”为业务职责，实际访问还需要患者范围授权及相应能力；当前为三个 DEMO 身份，正式账号管理未实现。
- “对应页面”为建议的页面或交互位置，**不代表已查验前端伙伴的页面实现**。
- 本表当前所有已实现行均为“后端已实现（DEMO）／伙伴页面待联调”。本机及云端接口验收通过不能替代伙伴页面验收。
- 接口均省略 `/ncd-ai` 前缀；字段、修订号、幂等键以 [接口文档](https://120.26.14.242/ncd-ai/doc.html) 为准。

## 不能按普通 CRUD 理解的边界

| 场景 | 当前规则 |
|---|---|
| 删除 | 没有独立删除患者、整份方案、任务包、审核记录或打卡记录的接口；编辑草稿可调整子条目集合。撤回不是删除。 |
| 管理侧重与权重 | 部分能力内嵌在生成、采用和编辑中，没有独立的“保存权重”接口；计算结果与来源绑定，不能把所有权重当任意可编辑数字。 |
| AI 生成 | 作业成功只表示候选通过程序校验；采用、送审、批准分别操作，不会自动发布。 |
| 七维 | 用药、饮食、运动、起居、监测、中医、其他按需启用；用药、中医缺少专业来源时保持关闭或阻断，不表示完整专业能力已经实现。 |
| 已批准内容 | 不能直接修改已批准方案或任务；需要新版本及重新审核。任务内容不能任意替换已审医学来源。 |
| 正式任务 | 必须来自二审通过并正式发布的排程；草稿不是患者今日任务。 |
| 反馈更正 | 追加新记录并更新当前汇总，旧反馈仍保留；不自动关闭安全事件。 |
| 发布通知 | 能查询通知配置状态，但真实短信、微信、App 推送尚未接入。 |
| 旧前端 | 已有四个旧契约入口；旧工作流、审核、派生、发布等路由尚未全部适配。不得把原生接口存在视作旧页面可直接使用。 |
