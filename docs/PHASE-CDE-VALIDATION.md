## 独立审查及修复

完成一次独立只读全分支审查；7项实质问题全部接受并在同一次修复中逐项复现、修复、回归。没有搁置的轻微问题，也没有“超出范围而不判断”的条目。修复后未再增加第二位审查人，以失败测试和全量回归验证修复。

| 问题 | 已验证的修复 |
|---|---|
| 等待患者锁时当前方案指针过期 | 锁后重新读取；并发创建新版与旧来源生成请求返回409，不生成旧包 |
| 克隆方案导致条目ID变化、边界重复任务 | 使用冻结执行动作、主体、维度、专业参数及日期/槽位匹配；新版来源ID不同也保留一个边界执行 |
| 同药补记只按groupId限制 | 确认药物身份跨组匹配；另检查已发布的更早下一剂，不能在下一剂开始后补记上一剂 |
| 回溯生效时刻取消已开始任务 | ALL_FUTURE要求不早于服务器当前时间；预览后跨过边界也拒绝发布 |
| 作息正常截止可被偏移覆盖 | 固定次日12:00；冲突配置返回BLOCKER |
| 跨日监测的补记截止早于正常窗口 | 检查截止顺序，冲突窗口不能二审或发布 |
| 模板失效导致待审无法结束 | 撤回/退回保留身份、状态、修订和摘要检查，允许结束审核；批准/发布仍要求模板有效 |
